## 📚 Learning Objectives — Object-Oriented Programming

Through my coursework, I'm working toward:

- **Understanding Classes & Objects** — designing classes that model real-world entities (e.g. `Vehicle`, `Movie`) with meaningful attributes and behaviors
- **Encapsulation** — organizing fields and methods within classes, and using constructors to properly initialize objects
- **Code Reusability** — refactoring repetitive code into reusable structures (like using arrays and loops instead of manually declaring each object)
- **Inheritance** — learning how classes can extend other classes to share and override behavior
- **Polymorphism** — understanding how objects of different classes can be treated through a common interface
- **Abstraction** — hiding internal implementation details and exposing only what's necessary
- **Debugging & Problem Solving** — reading compiler errors, tracing issues across files, and fixing them methodically
- **Version Control with Git** — using branches, commits, pull requests, and merges to manage code changes collaboratively (as done in my `Lab Activity 2` project)
